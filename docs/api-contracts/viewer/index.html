ZaryaWebsite API: проект для согласования

Foundation: Auth, Email, TwoFactor, Recovery, Profile, AdminUsers, Owner. Core: News, Updates, Comments, Reactions, Moderation, CMS. Extended: WorldMachine, CMSBatchPublishing, PressKitArchive, CMSRevisionCompare.

Используйте фильтр по тегу; для поиска маршрута откройте индекс операций в руководстве. Выполнение запросов отключено. Источник: актуальный openapi.yaml. Руководство.

Загрузка Swagger UI 5.17.14 с CDN. Для интерфейса нужен доступ к cdn.jsdelivr.net; спецификация читается локально.
