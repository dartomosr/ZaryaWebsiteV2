# История API-контракта ZaryaWebsite

## [0.1.0] — 02.11.2026 — ПРЕДЛОЖЕН

- Введена трёхзонная модель стабильности контракта (фундаментальная, основная, расширенная).
- Создана зона 1: сессии, регистрация, email-подтверждение, профиль, собственные параметры, 2FA и резервные коды, ручное восстановление пароля и 2FA, аварийная процедура Owner, управление ролями и передача единственного Owner.
- Введены общий JSON-формат ошибок, серверная cookie, CSRF-механизм и состояния авторизации. HTTP/DTO/имя cookie — **предложения**, не подтверждение backend.
- Сохранён прежний **предварительный** формат списка новостей из frontend/MSW в зоне 2.
- Создан пустой валидный каркас зоны 3, без спекулятивных маршрутов.
- Создан единый OpenAPI-файл для инструментов и валидатор структурной целостности.
