# ZaryaWebsite

Сайт игры **«ЗАРЯ: Марш Революции»**. В репозитории находятся три React-приложения, ASP.NET Core API, файловое хранилище и проект API-контракта.

## Запустить сайт

Нужны Node.js **24.x** и npm **11 или новее**. Из корня репозитория:

```powershell
cd Frontend
npm.cmd ci
npm.cmd run dev:web:mock
```

Откройте [главную](http://127.0.0.1:5173/) или [новости](http://127.0.0.1:5173/news). Этот режим использует тестовые данные и не требует сервера или БД. Остановка: `Ctrl+C`.

## Что работает

- Публичный сайт: главная с иллюстрацией, кратким описанием игры, пробным терминалом Мировой Машины и тремя последними новостями, список с подгрузкой и кэшированием, мобильное меню, заглушки разделов «Обновления», «Материалы» и «Вход», страница 404. Терминал открывает полноэкранную заглушку описания игры без смены адреса.
- CMS и модерация: отдельные закрытые оболочки. Авторизация и рабочие защищённые экраны ещё не реализованы.
- Backend: чтение новостей, обновлений и изображений из JSON и файлов. БД не используется.
- OpenAPI описывает более широкий проект API; наличие операции в контракте не означает её реализацию.

Frontend и backend пока расходятся в поле обложки новости. Для знакомства с интерфейсом используйте mock-режим; подключение настоящего API описано в [инструкции backend](Backend/README.md#совместимость-с-frontend).

## Проверить frontend

Из каталога `Frontend`:

```powershell
npm.cmd run check
```

Команда проверяет форматирование, ESLint, типы, unit/компонентные тесты и собирает все три приложения. Браузерные E2E запускаются отдельно.
