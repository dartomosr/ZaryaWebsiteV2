# Вебсайт «ЗАРЯ»

Официальный сайт игры **«ЗАРЯ: Марш Революции»**: информация об игре, новости, обновления, материалы для прессы и общение с игроками.

## Состояние проекта

Во frontend заново созданы главная с тремя последними новостями и список /news: подгрузка, состояния загрузки, пустого ответа и ошибки, повторная попытка. Доступны вымышленные данные MSW. CMS и модерация имеют отдельные закрытые оболочки без рабочей авторизации. Регистрация, профиль, комментарии, реакции, редакторы и Мировая Машина не объявляются реализованными.

Целевая архитектура frontend: **Feature-Sliced Design отдельно в каждом из трёх приложений**. Документация обновлена 18.11.2026; публичное приложение уже использует FSD, CMS и модерация пока сохраняют прежнюю структуру. В репозитории есть каркас ASP.NET Core 10; интеграция с реальным API не подтверждена. Наличие OpenAPI не означает готовность серверных операций.

## Стек и структура

Frontend использует React, JavaScript/JSX, Vite, npm workspaces и строгий JSDoc/CheckJS. Серверный стек: ASP.NET Core/C#, с целевыми Entity Framework Core и Microsoft SQL Server. Архитектурная работа над frontend не изменяет backend.

```text
Frontend/
  apps/web/                    # публичный сайт
  apps/cms/                    # управление контентом
  apps/moderation/             # модерация
  mocks/                       # MSW и тестовые данные
  tests/e2e/                   # сквозные сценарии
  scripts/                     # проверка production-сборки
  README.md                    # запуск и окружение
  AGENTS.md                    # инструкции агентов
  docs/                        # архитектура, требования, временный план и ADR
Backend/                       # сервер, только чтение в frontend-задачах
ApiContracts/                  # OpenAPI, руководства и проверки контрактов
Storage/                       # материалы и данные проекта
```

Общие frontend-пакеты появятся при фактической потребности; сейчас их нет. Данные браузер получает через HTTP API. Список новостей использует JSON с coverUrl; обложки загружаются отдельно. Файлы из форм передаются через multipart/form-data.

## Быстрый запуск

Нужны Node.js **24.x** и npm **>=11**. Из корня репозитория:

```powershell
cd Frontend
npm.cmd ci
npm.cmd run dev:web:mock
```

Откройте [новости с тестовыми данными](http://127.0.0.1:5173/news). Обычный npm run dev:web требует API для загрузки новостей. Команды npm run dev:cms и npm run dev:moderation запускают отдельные оболочки. Порты, окружение, preview и сценарии описаны в [инструкции frontend](Frontend/README.md).

Из Frontend команда npm run check последовательно выполняет проверку Prettier, ESLint, CheckJS, Vitest и сборку всех приложений. Первоначальное внедрение стандарта не включает массовое форматирование, поэтому существующие файлы пока могут не проходить проверки стиля; подробности в [инструкции frontend](Frontend/README.md#переход-существующего-кода). Playwright запускается отдельно командой npm run test:e2e. Контрактные проверки описаны в [документации API](ApiContracts/README.md). Эти команды являются инструкцией, а не заявлением об успешном запуске.
