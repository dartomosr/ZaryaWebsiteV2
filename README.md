# Вебсайт «ЗАРЯ»

Официальный сайт игры **«ЗАРЯ: Марш Революции»**. Сайт предназначен для знакомства с игрой, публикации новостей и обновлений, общения с игроками и предоставления материалов для прессы.

## Текущее состояние

Создан начальный frontend-каркас: три отдельных React-приложения, настройка разработки, автоматические проверки и сборка. Публичный сайт показывает страницу разработки, CMS и модерация пока закрыты до подключения серверной проверки доступа.

Основные возможности ниже запланированы. Серверный код, SQL-скрипты и интеграция API ещё не реализованы.

## Возможности

| Часть проекта | Планируемые функции |
| --- | --- |
| Публичный сайт | Описание игры, FAQ, новости, обновления со списками изменений, PressKit с изображениями и ZIP-архивом |
| Учётная запись | Регистрация, вход и выход, профиль, изменение имени, email, пароля и аватара |
| Общение | Комментарии к новостям, удаление собственных комментариев, положительные и отрицательные реакции с возможностью снятия |
| CMS | Создание, редактирование и удаление новостей и обновлений; черновики, публикация и загрузка изображений |
| Модерация | Просмотр комментариев и удаление с явным подтверждением |

Публичный сайт рассчитан на экраны от **320 px**, CMS и модерация на рабочую ширину от **1024 px**. На главной предусмотрено до трёх последних опубликованных материалов каждого типа. Визуальное оформление: тёмная палитра, белый текст, жёлто-оранжевые и фиолетовые акценты.

**Подписки, рассылки и почтовые уведомления исключены из текущей версии.** Email сохраняется как поле учётной записи.

## Архитектура

В одном репозитории размещаются клиентская и серверная части с раздельной ответственностью.

- **Frontend:** три независимых приложения на **React + JavaScript/JSX + Vite**, объединённые через npm workspaces. Публичный сайт, CMS и модерация имеют собственные интерфейсы и сборки.
- **Backend (планируется):** единый **ASP.NET Core API**, **Entity Framework Core**, **Microsoft SQL Server** и файловое хранилище изображений.
- **Обмен данными:** браузер обращается только к API. Для данных используется JSON, для загрузки изображений предусмотрен `multipart/form-data`.
- **Доступ:** сессию определяет серверная cookie. Перед отображением CMS и модерации API должен подтвердить роль `Admin` или `Moderator`; окончательный контроль прав выполняется на сервере.
- **Контент:** описание игры, FAQ и PressKit входят в frontend-сборку. Новости, обновления, пользователи, комментарии и реакции обслуживаются через API.

Серверную часть ведёт другой разработчик. В рамках frontend-работ backend доступен только для чтения. Отдельные SQL-скрипты для закреплённых таблиц `News` и `Updates` готовятся после согласования схемы с владельцем backend. Адреса API, DTO и настройки cookie/CORS/CSRF пока требуют согласования.

## Локальный запуск

Требуются **Node.js 24.x** и **npm >=11**. Из корня репозитория:

```powershell
cd Frontend
npm ci
npm run dev:web
```

Остальные приложения запускаются из `Frontend` в отдельных терминалах:

| Приложение | Команда | Адрес |
| --- | --- | --- |
| Публичный сайт | `npm run dev:web` | [127.0.0.1:5173](http://127.0.0.1:5173) |
| CMS | `npm run dev:cms` | [127.0.0.1:5174](http://127.0.0.1:5174) |
| Модерация | `npm run dev:moderation` | [127.0.0.1:5175](http://127.0.0.1:5175) |

Для запуска текущих оболочек backend не требуется. Полноценная работа с данными станет доступна после подключения согласованного API.

## Проверки и сборка

Все команды выполняются из `Frontend`:

| Команда | Назначение |
| --- | --- |
| `npm run lint` | Статический анализ ESLint |
| `npm run typecheck` | Проверка JavaScript через CheckJS и JSDoc без перехода на TypeScript |
| `npm run test:unit` | Быстрые тесты Vitest и React Testing Library |
| `npm run build` | Сборка всех трёх приложений в `apps/<имя>/dist` |
| `npm run check` | Последовательный запуск всех перечисленных проверок и сборки |
| `npm run test:e2e` | Отдельные браузерные сценарии Playwright |

Playwright подготовлен для проверки оболочек и экранов 320/768/1024/1440 px. Перед первым запуском требуется `npx playwright install chromium`; E2E-команда самостоятельно запускает три dev-сервера. Браузерные проверки выполняются отдельно от `npm run check`.
