# Вебсайт «ЗАРЯ»

Официальный сайт игры **«ЗАРЯ: Марш Революции»**: информация об игре, новости, обновления, материалы для прессы и общение с игроками.

## Состояние разработки

Работает клиентская страница `/news`: список новостей, кнопка «Показать ещё», загрузка, пустое состояние, ошибки и повторная попытка. Доступен режим разработки с вымышленными данными MSW. Главная пока содержит стартовый экран и ссылку на новости. CMS и модерация имеют отдельные закрытые оболочки.

В репозитории есть каркас ASP.NET Core 10 с подключением контроллеров и OpenAPI, но прикладные обработчики API, EF-модели и SQL-скрипты пока отсутствуют. Интеграция с реальным API не проверена. Регистрация, профиль, комментарии, реакции, редактирование материалов, полный контент игры и PressKit находятся в разработке.

## Возможности проекта

| Часть | Назначение |
| --- | --- |
| Публичный сайт | Описание игры, FAQ, новости, обновления со списками изменений, PressKit с ZIP-архивом |
| Учётная запись | Регистрация, вход, выход и редактирование профиля |
| Общение | Комментарии и реакции к новостям |
| CMS | Создание и редактирование новостей и обновлений, черновики, публикация, изображения |

Таблица описывает целевой функционал; реализованный участок указан выше. Подписки, рассылки и маркетинговые уведомления в текущую версию не входят. Актуальный проект API предусматривает служебное подтверждение email и восстановление доступа; эти функции ещё не реализованы.

## Архитектура и структура

Клиентская часть состоит из трёх независимых приложений **React + JavaScript/JSX + Vite**, объединённых npm workspaces. Целевая серверная часть: единый **ASP.NET Core API**, **Entity Framework Core**, **Microsoft SQL Server** и хранилище изображений. Сейчас сервер представлен начальным каркасом без прикладной реализации.

Обычные данные передаются через HTTP/JSON, изображения загружаются через `multipart/form-data`. Для `GET /api/news` обязателен `multipart/mixed` с JSON-метаданными и бинарными обложками по требованию backend-разработчика. В режиме разработки MSW перехватывает те же запросы. Браузер напрямую к БД не подключается. Авторизация через серверную cookie является целевым требованием, её интеграция в разработке.

```text
Frontend/
  apps/web/                    # публичный сайт
  apps/cms/                    # CMS
  apps/moderation/             # модерация
  mocks/                       # обработчики MSW и вымышленные данные
  tests/e2e/                   # браузерные сценарии
  scripts/verify-web-build.js   # проверка production-ресурсов
  package.json                 # npm workspaces и команды
Backend/
  BACKEND_INTEGRATION.md        # контракты и открытые вопросы API
README.md                      # обзор проекта
LICENSE.md                     # условия использования
```

## Быстрый запуск

Нужны **Node.js 24.x** и **npm >=11**. Из корня репозитория:

```powershell
cd Frontend
npm ci
npm run dev:web:mock
```

Откройте [новости с тестовыми данными](http://127.0.0.1:5173/news). Обычный запуск `npm run dev:web` не включает MSW и требует API для загрузки новостей. CMS и модерация запускаются командами `npm run dev:cms` и `npm run dev:moderation` в отдельных терминалах.

Из `Frontend` команда `npm run check` выполняет ESLint, CheckJS, Vitest и сборку трёх приложений. Браузерные сценарии запускаются отдельно; подробности и конфигурация приведены в инструкции frontend.
